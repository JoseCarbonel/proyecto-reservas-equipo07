# Sistema de Gestión de Reservas - Grupo 07

## Objetivo del proyecto
Desarrollar un sistema para gestionar clientes, servicios y reservas de una empresa.

## Funcionalidades principales
- Registro y consulta de clientes.
- Registro y consulta de servicios.
- Registro, consulta y cancelación de reservas.

## Herramientas
- Git y GitHub para el control de versiones.
- Trello para organizar y dar seguimiento a las tareas.
